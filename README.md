## 📋 Требования

Для работы проекта необходимы **Python**, виртуальное окружение и пакетный менеджер **uv**.

| Компонент |  Минимальная версия  |
| :-------- | :------------------: |
| 🐍 Python |      **3.13+**       |
| 📦 uv     | последняя стабильная |

Проверьте установленную версию Python:

```bash
python --version
uv --version
```

## 🚀 Локальный запуск

- Клонируйте репозиторий и перейдите в папку проекта:

  ```bash
  git clone https://github.com/Skip-Bug/Ai-web-generator.git ai-web-generator
  cd ai-web-generator
  ```

### Создание виртуального окружения для работы с IDE

IDE для корректной работы подсказок необходимо развернуть виртуальное окружение со всеми установленными зависимостями.

В качестве пакетного менеджера на проекте используется [uv](https://docs.astral.sh/uv/).

Если uv ещё не установлен — воспользуйтесь [инструкцией по установке.](https://gitlab.dvmn.org/root/fastapi-articles/-/wikis/Uv-package-manager#1-%D1%83%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0-uv)  
 В корне репозитория выполните команду:

```shell
$ uv sync
```

[uv](https://docs.astral.sh/uv/) создаст виртуальное окружение, установит необходимую версию Python и все необходимые зависимости.

После этого активируйте виртуальное окружение в текущей сессии терминала:

```shell
$ source .venv/bin/activate  # для Linux
$ .\.venv\Scripts\activate  # Для Windows
```

Узнать версию python, которая установлена в виртуальном окружении можно с помощью команды:

```shell
$ python -V
```
