# 🚀 FastAI — AI Web Generator

> Генератор веб-приложений на базе искусственного интеллекта

---

## 📋 Требования

Для работы проекта необходимы **Python**, виртуальное окружение и пакетный менеджер **uv**.

| Компонент |  Минимальная версия  |
| :-------- | :------------------: |
| 🐍 Python |      **3.13+**       |
| 📦 uv     | последняя стабильная |

Проверьте установленную версию Python:

```bash
python --version
uv --version
```

## 🚀 Локальный запуск

- Клонируйте репозиторий и перейдите в папку проекта:

  ```bash
  git clone https://github.com/Skip-Bug/Ai-web-generator.git ai-web-generator
  cd ai-web-generator
  ```

### Создание виртуального окружения для работы с IDE

IDE для корректной работы подсказок необходимо развернуть виртуальное окружение со всеми установленными зависимостями.

В качестве пакетного менеджера на проекте используется [uv](https://docs.astral.sh/uv/).

Если uv ещё не установлен — воспользуйтесь [инструкцией по установке.](https://gitlab.dvmn.org/root/fastapi-articles/-/wikis/Uv-package-manager#1-%D1%83%D1%81%D1%82%D0%B0%D0%BD%D0%BE%D0%B2%D0%BA%D0%B0-uv)  
 В корне репозитория выполните команду:

```shell
$ uv sync
```

[uv](https://docs.astral.sh/uv/) создаст виртуальное окружение, установит необходимую версию Python и все необходимые зависимости.

После этого активируйте виртуальное окружение в текущей сессии терминала:

```shell
$ source .venv/bin/activate  # для Linux
$ .\.venv\Scripts\activate  # Для Windows
```

Узнать версию python, которая установлена в виртуальном окружении можно с помощью команды:

```shell
$ python -V
```

## ⚙️ Переменные окружения

> ⚠️ **Важно:** Файл `.env` содержит секретные данные (API-ключи) и **не должен** попадать в репозиторий. Он уже добавлен в `.gitignore`.

Создайте файл `.env` в корне проекта, скопировав шаблон:

```bash
cp example.env .env
```

Затем откройте `.env` и заполните переменные, значения которых необходимо получить externally.

### Основные настройки

| Переменная     | Тип    | По умолчанию            | Описание                                                                                |
| :------------- | :----- | :---------------------- | :-------------------------------------------------------------------------------------- |
| `DEBUG`        | `bool` | `false`                 | Режим отладки. При включении активирует подробное логирование.                          |
| `MOCK_MODE`    | `bool` | `false`                 | Режим мок-тестов. Включает имитацию внешних вызовов.                                    |
| `BASE_URL`     | `str`  | `http://127.0.0.1:8000` | Базовый URL приложения. Используется для формирования внутренних ссылок и URL сервисов. |
| `API_PREFIX`   | `str`  | `/frontend-api`         | Префикс маршрутов для фронтенд-API.                                                     |

### DeepSeek (LLM)

DeepSeek необходим для генерации HTML-кода по запросу пользователя. Для работы с ним потребуется оплатить доступ к серверам [API DeepSeek](https://api-docs.deepseek.com/quick_start/pricing/). Достаточно 1 доллара, чтобы хватило на все тесты в рамках обучения.

| Переменная                  | Тип         | По умолчанию        | Описание                                                                                                                                                      |
| :-------------------------- | :---------- | :------------------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `DEEPSEEK__API_KEY`         | `SecretStr` | _(обязательна)_     | API-ключ для доступа к модели DeepSeek. Получить ключ: [DeepSeek Platform → API Keys](https://platform.deepseek.com/) → зарегистрироваться → создать API Key. |
| `DEEPSEEK__MAX_CONNECTIONS` | `int`       | не ограничено       | Максимальное количество одновременных соединений к API.                                                                                                       |
| `DEEPSEEK__TIMEOUT`         | `int`       | `120`               | Таймаут запросов к API в секундах.                                                                                                                            |
| `DEEPSEEK__BASE_URL`        | `str`       | автоопределяется    | Пользовательский URL API DeepSeek (по умолчанию https://api.deepseek.com).                                                                                    |
| `DEEPSEEK__MODEL`           | `str`       | модель по умолчанию | Имя используемой модели DeepSeek.                                                                                                                             |

### Unsplash (Изображения)

Unsplash предоставляет бесплатное API для поиска изображений в фотостоке. Подобранные изображения добавляются на сгенерированный сайт.

**Как получить API-ключ:**
Зарегистрируйте аккаунт на [unsplash.com](https://unsplash.com/)
Создайте [demo-приложение](https://unsplash.com/oauth/applications)
Скопируйте токен доступа, [скриншот](https://dvmn.org/media/filer_public/de/2f/de2fe81a-6823-4d85-a9a5-0033675fd39a/screenshot.png)

| Переменная                  | Тип         | По умолчанию   | Описание                                                                                                                   |
| :-------------------------- | :---------- | :------------- | :------------------------------------------------------------------------------------------------------------------------- |
| `UNSPLASH__API_KEY`         | `SecretStr` | _(обязателен)_ | Access Key из настроек вашего приложения. Получить: [Unsplash Developers → Apps](https://unsplash.com/oauth/applications). |
| `UNSPLASH__MAX_CONNECTIONS` | `int`       | не ограничено  | Максимальное количество одновременных соединений к API.                                                                    |
| `UNSPLASH__TIMEOUT`         | `int`       | `20`           | Таймаут запросов к API в секундах.                                                                                         |
| `UNSPLASH__PROXY`           | `str`       | _(нет)_        | HTTP-прокси для запросов к Unsplash.                                                                                       |
